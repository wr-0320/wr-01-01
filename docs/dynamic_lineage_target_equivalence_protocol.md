# Target-relevant lineage equivalence: final breakthrough protocol

Status: **one bounded theoretical audit; algorithms, alarms and simulations prohibited**

Date: 2026-10-20

## Sole question

Can target-relevant equivalence classes of evidence-lineage graphs produce a
strictly tighter valid situation-posterior certificate than the envelope over
the complete admissible graph set, without requiring full graph recovery?

## Frozen tests

1. **Validity:** the interval must retain finite-sample coverage of the true
   model posterior.
2. **Strict tightening:** an explicit condition must make the new interval a
   strict subset of the complete-graph posterior envelope.
3. **Observable assumptions:** tightening may use timestamps, partial provenance
   or trusted audits, but not the hidden true graph or unavailable target labels.
4. **Originality screen:** quotienting, projection and standard confidence sets
   for a lower-dimensional functional do not by themselves count as a new
   theoretical result.
5. **Operational relevance:** the result must address copying, common upstream
   evidence or lineage drift rather than an arbitrary nuisance parameter.

## Predeclared decisions

- **CONTINUE:** equivalence-class inference yields a valid strict improvement
  under auditable information and requires a result beyond standard projection
  or partial identification.
- **CONDITIONAL ONLY:** direct inference of a target-relevant functional is
  useful computationally or statistically, but follows from existing generic
  functional-inference machinery.
- **STOP:** quotienting preserves the complete posterior image, while any strict
  reduction requires additional identifying information or a stronger test and
  therefore does not arise from equivalence classes alone.

The audit ends with one result document and one decision. It may not open a new
literature matrix or be rescued by an online alarm component.
